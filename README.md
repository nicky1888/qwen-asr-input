# qwen-asr-input · 本地语音输入

macOS 菜单栏语音输入工具。按快捷键开始录音，再按一次结束，识别完的文字粘贴进开始录音时的输入框，不自动回车。识别模型跑在本机 Apple GPU（PyTorch MPS）上，不联网、不调云端，录音不落盘。

## 系统要求

- Apple Silicon 的 Mac，macOS 14 或更新（实测机器：M3 Max、36GB、macOS 26）。
- [uv](https://docs.astral.sh/uv/)（装 Python 3.12 和依赖），Xcode 命令行工具（`xcode-select --install`，构建 Dock 启动器要用 clang）。
- 空闲内存 4GB 以上：默认模型常驻约 2.7GB，长录音识别时峰值约 3.9GB。

## 安装

```zsh
git clone https://github.com/nicky1888/qwen-asr-input.git && cd qwen-asr-input
uv venv -p 3.12 .venv && uv pip install --python .venv/bin/python -r requirements.lock
cp config/vocab.example.txt config/vocab.txt     # 专有名词表，按需改
# 下载模型：本仓库不提供下载，见下一节「模型」，放到 data/models/Qwen3-ASR-0.6B
scripts/build-app.sh                              # 生成 ~/Applications/语音输入.app 并加进 Dock
```

第一次从 Dock 打开后，按「权限」一节勾上辅助功能，再退出重开。

## 模型

本仓库**不包含、也不代为下载**任何模型权重。请从下面的官方链接自行下载，放进 `data/models/` 下对应目录（该目录已被 git 忽略）。换路径用 `--model` 参数或环境变量 `QWEN_ASR_MODEL`。

**默认：Qwen3-ASR-0.6B**（官方原版 bf16，约 1.88GB）

- Hugging Face：<https://huggingface.co/Qwen/Qwen3-ASR-0.6B>
- ModelScope（国内）：<https://modelscope.cn/models/Qwen/Qwen3-ASR-0.6B>
- 本机实测用的版本：`5eb1441…`，权重文件 `model.safetensors` 的 SHA-256 是 `79d6cbd4c98c7bbffe9db2edac07f56cd6637d0d5944b27f6c2b8353840323ea`。

实测（M3 Max，合成语音）：35 秒口述 2.2 秒出字；常驻约 2.7GB，闲置卸载后进程只占约 0.7GB；断网可用。

**其他可选模型**

| 模型 | 参数量（上游公布） | 能否直接用 | 说明 |
|---|---|---|---|
| [Qwen3-ASR-1.7B](https://huggingface.co/Qwen/Qwen3-ASR-1.7B) | 1.7B | 能，`--model` 指向它的目录 | 同系列大号，更准，内存约是 0.6B 的 2–3 倍。本仓库未实测 |
| [SenseVoice-Small](https://huggingface.co/FunAudioLLM/SenseVoiceSmall) | 约 2.3 亿 | 不能，要写加载适配 | 非自回归，速度快，中文强，自带标点和数字规整。省内存的首选候选 |
| [Paraformer-zh](https://huggingface.co/funasr/paraformer-zh) | 约 2.2 亿 | 不能，要写加载适配 | FunASR 的中文模型，成熟，适合纯中文 |
| [Whisper large-v3-turbo](https://huggingface.co/openai/whisper-large-v3-turbo) | 约 8 亿 | 不能，要写加载适配 | 多语言，英文好；中文可能出繁体或漏标点 |

「不能直接用」是说本工具目前只接了 Qwen3-ASR 的加载代码（`src/voice_input.py` 的 `load_asr`），换别的模型要改这一个函数。表里除 0.6B 以外的内存和准确度都没有实测，选之前请自己测。

想省内存又不换模型：控制面板设置页把「闲置卸载模型」调小，比如 5 分钟。卸下后进程只占约 0.7GB，下次按快捷键时边录边重新加载，约 2 秒。

## 用法

Dock 里的麦克风图标「语音输入」（`~/Applications/语音输入.app`）：没在跑时点一下就启动；在跑时点一下，打开控制面板。

控制面板有三页。首页看状态、模型是否卸下、内存和用量统计，并能复制上次结果；设置页改快捷键、闲置卸载分钟数、单次录音上限，保存后立即生效；词表页直接编辑专有名词表。统计只读日志里的次数、时长、字数，不含口述内容。省时是估算值：按每分钟打 40 字算出打字时间，再减去说话时间。关掉面板，窗口就释放，不常驻占内存。设置页最下面可以切换界面语言（中文 / English），面板、菜单栏和各种提示一起切换，存在 `config/settings.json` 的 `language` 键里。面板开着、焦点在面板里时按快捷键，结果不会粘进面板，会留在「复制上次结果」。

命令行也能管（在仓库目录下）：

```zsh
scripts/voice-input start    # 等同点 Dock 图标，约 10 秒后菜单栏沙漏变麦克风即就绪
scripts/voice-input status   # 是否在跑、内存占用、最近 3 条状态
scripts/voice-input stop     # 退出，模型和麦克风随进程释放
scripts/voice-input run      # 前台运行，Ctrl+C 退出，调试用
```

- **快捷键**：默认 ⌥⇧Space 切换录音，可以改成带 fn 的组合。录音中按 Esc 取消，取消后不插入。
- **换快捷键**：菜单「更改快捷键…」，直接按下新组合。fn ⌃ ⌥ ⇧ ⌘ 可以任意组合，再加字母、数字或空格；也可以单按 F 键，但 F 键不能配 fn，因为系统给 F 键自带 fn 标记，分不清是不是真按了。改完立即生效，存进 `config/settings.json`，重启后保留。
- **快捷键冲突**：程序查不出别的 App 是不是也在用同一组合。Typeless、Wispr Flow 默认用 fn，开着它们会跟带 fn 的组合打架，要退出。fn+E（表情）、fn+F（全屏）、fn+C、fn+N、fn+Q、fn+A、fn+H 是系统自带的 fn 快捷键，别选。
- **录音浮条**：录音时屏幕底部居中弹出一个小胶囊，红点、跟着音量跳的波形和录音时长；识别时变成蓝点和流动波形，写「识别中」；回到就绪就收起。浮条不抢焦点、不挡鼠标，全屏 App 和各个桌面上都能看到。
- **菜单栏图标**：沙漏表示加载中，麦克风表示就绪，红色实心麦克风表示录音中，波形表示识别中，三角感叹号表示失败。
- **管理菜单**（点菜单栏图标）：打开控制面板、状态和最近一次结果、复制上次结果、把上次结果插入当前输入框、取消本次录音、更改快捷键、编辑专有名词表（用文本编辑打开）、查看日志、退出。
- **提示音**：开始录音响 Tink，结束响 Pop，没插入或出错响 Basso。
- **单次上限**：默认 120 秒，到时自动结束并识别。在控制面板设置页改，命令行 `--max-seconds` 优先。
- **内存**：模型在时占 2.7GB 左右。识别 2 分钟长录音时会冲到约 3.9GB，识别完就清掉 GPU 缓存、降回来。闲置 10 分钟自动卸下模型，降到约 0.7GB。卸下后再按快捷键，模型和录音同时加载，约 2 秒，一般说完话前就加载好了。闲置时长在控制面板设置页改，0 表示一直常驻。
- **清理语气词**（默认开，设置页可关）：识别完用规则删掉嗯、呃、单独成段的啊/哦/额，句首紧跟逗号的「那个，」「就是，」，以及两字以上紧挨着的重复（「就是就是」「我觉得，我觉得」）。不改写句子、不换词、不加结构，「好啊」「谢谢」「额度」「那个周报」不动。识别模型本身是逐字转写，在上下文里写指令让它去语气词，实测无效，所以放在识别之后做。规则在 `src/cleanup.py`。
- **数字用阿拉伯数字**（默认开，设置页可关）：识别模型在中文里一律用汉字写数字，上下文提示也改不了，所以识别后用规则转换。会转：百分之十二点五 → 12.5%、一千二百三十美元 → 1230美元、十月二十八号下午三点半 → 10月28号下午3点半、两万五千台 → 25000台、三点五万 → 3.5万、二零二六年 → 2026年。保持汉字：一起、一定、十分重要、万一、千万别、七八个、五六十、两个、第一、一刀切、一块儿、一日三餐。单个数字只在跟着计量单位（号、岁、美元、万、小时等）时才转。规则在 `src/cn_numbers.py`，先清语气词再转数字。
- **专有名词表**：`config/vocab.txt` 一行一个词，作为上下文提示模型，改完下一次识别就生效。实测能把 PyTorch、caffeinate、bootstrap 这类词纠对。仓库里只有示例 `config/vocab.example.txt`，自己的词表 `config/vocab.txt` 被 git 忽略。

## 什么时候不粘贴

识别结果都会留在菜单的「复制上次结果」里，以下情况只响 Basso、不粘贴：

- 录音期间切了 App，或者输入焦点换了控件；
- 目标是密码框，或系统处在安全输入状态；
- 焦点不在可编辑区域，或这个 App 不给读焦点；
- 没录到声音（峰值低于 0.01，麦克风没授权时录到的全是零），或识别结果为空。

粘贴走临时剪贴板加 ⌘V。粘完 0.6 秒后恢复原剪贴板，文字、图片等各类型都按原样写回；这 0.6 秒里你又复制了东西，就不覆盖。文件拖拽这类延迟提供的剪贴板内容恢复不了。

## 权限

从 Dock 启动时，权限挂在「语音输入」这个 App 名下；前台 `run` 调试时，挂在当前终端名下。只需要两项：

- **辅助功能**：读焦点控件、发 ⌘V。系统设置 → 隐私与安全性 → 辅助功能，勾上「语音输入」，然后退出再从 Dock 重开。
- **麦克风**：第一次录音时系统会弹窗，点允许。

重跑 `scripts/build-app.sh` 会重新签名，macOS 可能把这两项权限清掉，要再勾一次。

快捷键靠全局键盘监听实现，跟粘贴共用辅助功能权限，没有单独的「输入监控」权限。系统里每个按键都要等监听放行才往下走，所以判断和吞键都写在原生代码 `src/keytap.c` 里，跑在高优先级线程上，不经过 Python。v09 及以前用 Python 判断，模型重新加载时 Python 一次被占住 0.6 秒，整台机器的键盘跟着卡。命中快捷键的按键会被吞掉，不传给前台 App，其他按键原样放行。程序还关掉了 App Nap，免得后台闲置时被系统降速。

## 文件

- `src/voice_input.py`：主逻辑；`src/panel.py` + `src/panel.html`：控制面板（同进程 WKWebView，离线）；`src/stats.py`：日志统计；`src/i18n.py`：中英文切换；`src/cleanup.py`：语气词清理；`src/cn_numbers.py`：中文数字转阿拉伯数字；`src/keytap.c`：原生键盘监听，启动时按需用 clang 编译到 `out/libkeytap.dylib`（git 忽略）；`src/audiorec.c`：原生 AudioQueue 录音，启动时按需编译到 `out/libaudiorec.dylib`（git 忽略）；`src/overlay.py`：录音浮条；`scripts/voice-input`：启停脚本。
- `app/launcher.m`：Dock 启动器，几十行 Objective-C。它把 Python 主程序拉起来当子进程，权限因此算在 App 名下；运行中点 Dock 时，它通知主程序打开控制面板。`app/make_icon.py` 画图标。`scripts/build-app.sh` 编译、签名、装到 `~/Applications`，第一次运行时加进 Dock。
- 模型：`data/models/`（git 忽略），来源和校验值见「模型」一节。
- 依赖：`.venv`（Python 3.12，uv），精确版本见 `requirements.lock`。重建：`uv venv -p 3.12 .venv && uv pip install --python .venv/bin/python -r requirements.lock`。
- 日志：`~/Library/Logs/qwen-asr-input.log`，只记状态、耗时、字数，不记口述原文。录音只在内存里，不落盘。

## 常见故障

- **菜单栏找不到图标**：菜单栏图标太多时会被挤掉，点 Dock 图标就能弹出菜单。`voice-input status` 看是否在跑，日志末尾看报错。
- **按快捷键没反应**：先看菜单第二行是不是「开不了键盘监听」，是就去辅助功能里勾上「语音输入」后重开。也可能是别的程序抢了这个组合，从菜单换一个。以下情况系统不把按键交给监听，快捷键也就不响应：屏幕锁定时；焦点在密码框里时（终端开了「安全键盘输入」也一样）。
- **总提示没录到声音**：系统设置 → 隐私与安全性 → 麦克风，勾上「语音输入」；或检查输入设备。
- **总提示拿不到焦点**：系统设置 → 隐私与安全性 → 辅助功能，勾上「语音输入」后退出重开。
- **打字卡顿、按键被吞**：看日志里「键盘监听被系统停用」那几行，括号里写了原因。「回调超时」说明监听线程被拖住了，请把日志前后几分钟发给维护者；「安全输入或权限变动」多半是重建了 App 或开了密码框，按上一条重新授权。
- **提示「已经在运行」**：已有一个实例在跑，先从菜单退出或 `voice-input stop`。

## 测试

- `.venv/bin/python -m pytest -q tests/test_units.py`：快捷键、设置、剪贴板恢复、词表、闲置卸载、日志统计、语言切换、语气词清理、数字转换、原生监听的吞键规则、浮条音量映射、原生录音缓冲区、分段识别、开麦失败与超时、识别看门狗及焦点检查，共 30 个，不需要模型权重；分段测试需要已安装的 qwen_asr 依赖。
- `.venv/bin/python tests/bench.py`：无界面基准，测延迟、内存、连续 10 次、静音。样本在 `data/samples`（git 忽略）。
- `tests/e2e_drive.py <wav>`：模拟按快捷键，外放样本让麦克风收音，再按一次结束。屏幕要解锁，并先把焦点放到目标输入框。
